# captain-cluster

Everything scoped to one cluster environment: the cluster Route53 zone with
DNSSEC, per-cluster IAM, the captain repository and its generated files, and
**every platform version pin** (`platform-versions.tf`). Instantiate once per
cluster environment; the `?ref=` on each block is that cluster's independent
version knob. See [docs/migration/MIGRATION.md](../../docs/migration/MIGRATION.md).

## Providers the caller must pass

| Provider | Used for |
|----------|----------|
| `aws.clientaccount` | cluster zone + DNSSEC, delegation records into the parent zone, per-cluster IAM |
| `aws.primaryregion` / `aws.replicaregion` | the loki S3 bucket and its replication |
| `github` (default, inherited) | the captain repository and its generated files — configure `provider "github"` at the root |
| `random` (default) | dex/grafana passwords and name uuids |

`tls`, `local`, and `http` are also pulled in by nested modules but need no
configuration — empty default configs are auto-created for them.

## Removing a cluster

Delete the `cluster_<env>` module block first (or in the same PR), then remove
the environment from `environment_names` on the tenant_base block. Shrinking
the list while the module block still exists fails its plan on purpose — the
covered-environments guard treats it as a missing entry.
